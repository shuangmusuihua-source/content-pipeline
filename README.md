# Content Pipeline

内容处理流水线：翻译 → 去AI味 → 多平台排版。

将英文内容转换为中文，优化表达，并输出为微信公众号、今日头条等平台的专业排版格式。

## 功能

- **翻译**：英文 → 中文 Markdown
- **去 AI 味**：识别并修复 AI 写作模式
- **多平台排版**：微信公众号、今日头条
- **浏览器预览**：生成 HTML 供复制粘贴

## 安装

```bash
npx skills add 你的用户名/content-pipeline
```

## 使用

提供英文网页链接或本地文本：

```
https://example.com/english-article
```

或：

```
翻译 ~/Documents/article.txt 并转成微信样式
```

## 流程

```
输入（URL/本地文件）
    ↓
1. 获取内容
    ↓
2. 翻译为中文 Markdown
    ↓
3. 去除 AI 写作痕迹
    ↓
4. 选择平台（微信/头条）
    ↓
5. 生成 HTML
    ↓
6. 浏览器预览
    ↓
7. 手动发布
```

## 支持的平台

| 平台 | 风格 |
|------|------|
| 微信公众号 | 暖色调、米色背景、印刷级排版 |
| 今日头条 | 白底黑字、红色强调、现代简洁 |

## 依赖

- `humanizer-zh` skill（去除 AI 写作痕迹）
